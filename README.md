# ping_monitor

一个基于 Tkinter 的全链路网络诊断看板，并发监控外网目标、本地网关和自定义目标，实时显示延迟、历史趋势、质量评分和智能故障定位。

## 功能

- 🌐 **多链路并发监控**：外网目标（默认 `223.5.5.5` 阿里 DNS，失败时自动切换备用 DNS）+ 本地网关（自动识别 / 可配置）+ 自定义目标（默认 `192.168.1.1`）
- 📈 **实时图表**：最近 60 秒动态折线 + 过去 24 小时趋势图，中断点高亮标记
- 📶 **延迟质量评分**：根据最近窗口内的平均延迟、抖动和丢包率判断「优秀 / 正常 / 高延迟 / 抖动 / 丢包 / 中断」
- 🤖 **智能故障诊断**：自动判定「本地路由器故障」还是「外部宽带故障」，给出处理建议
- 📊 **今日概览**：统计今日断网次数、累计断网时长、最长中断和责任倾向
- 📋 **历史断网责任判定**：记录每次外网中断时网关的状态，追溯责任方
- 📤 **报告导出**：支持导出今日 CSV / HTML 报告
- ⚙️ **运行时配置**：界面内修改外网目标、路由器 IP、自定义目标、Ping 间隔、超时、保留天数等
- 🧹 **数据清理**：一键清空历史延迟和断网记录
- 🗄️ **数据持久化**：SQLite 存储时间序列数据，保留 3 天，自动清理
- 🖥️ **跨平台**：支持 Windows / macOS / Linux

## 快速开始

```bash
pip install matplotlib
python ping_monitor.py
```

首次启动会自动创建 `ping_history.db` 数据库文件。

## 界面说明

| 区域 | 内容 |
|------|------|
| 顶部状态栏 | 外网 / 网关实时通断状态及延迟 |
| 左侧图表区（可滚动） | 外网 + 网关 + 自定义目标各自的 60s 实时图和 24h 趋势图 |
| 图表右侧 | 实时延迟数值、单次断网记录和中断持续时间统计 |
| 右侧诊断面板 | 实时故障判定、延迟质量评分、今日概览、导出/配置/清空按钮、历史责任判定表格 |

## 配置

可通过右侧「配置」按钮运行时修改，也可以调整脚本开头的常量区：

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `WAN_TARGETS` | `223.5.5.5`, `119.29.29.29`, `8.8.8.8`, `1.1.1.1` | 外网监控目标（优先级列表，自动切换） |
| `CUSTOM_TARGET` | `192.168.1.1` | 自定义监控目标 |
| `PING_INTERVAL` | `1` | Ping 间隔（秒） |
| `PING_TIMEOUT_MS` | `1000` | Ping 超时（毫秒） |
| `CLEANUP_AGE` | `259200` | 数据保留时长（秒，3 天） |
| `QUALITY_WINDOW` | `60` | 延迟质量评分窗口（秒） |
| `TABLE_ROW_LIMIT` | `200` | 表格最多显示的最近记录数 |
| `COMMON_GATEWAYS` | `192.168.x.x` 常见地址 | 网关自动识别失败时的兜底列表 |
